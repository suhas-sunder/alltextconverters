# Future-only backlog

These items are deliberately excluded from `current-implementation-plan.md`. Each expands the product, data model, privacy surface, operating cost, or index footprint without evidence that it is required for the current growth, CTR, trust, correctness, accessibility, performance, or AdSense-readiness phase.

Scores use `(impact × confidence × evidence strength) / (effort × risk)` and apply only relative to the current phase.
